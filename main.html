Time and Space Complexity

Time complexity measures how the run time of an algorithm grows as the size of the input data increases. An efficient algorithm uses fewer operations and scales well, meaning it stays fast even when the input data becomes very large

Space complexity measures the total amount of memory an algorithm needs to run to completion as a function of its input size (n). When an algorithm has O(n) space complexity (linear space), it means its memory consumption grows directly and proportionally with the size of the input.
